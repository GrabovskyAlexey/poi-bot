# Бэклог идей и улучшений

Идеи, собранные во время разработки MVP (этапы 0–4 из `docs/ROADMAP.md` закрыты). План работ по ним составляем **после успешного деплоя MVP**: каждую задачу оформляем отдельной папкой миграций в `src/main/resources/liquibase/<задача>/` (см. `AGENTS.md`).

Размер: **S** — часть дня, **M** — день–два, **L** — несколько дней.

## 1. Хвосты MVP
| Идея | Размер | Комментарий |
|---|---|---|
| Резерв: проверка членства в группе работает полноценно только если бот админ | S | Описать в справке/подсказке при добавлении бота |

## 2. UX
| Идея | Размер | Комментарий |
|---|---|---|
| Фильтр по тегу и статусу в `/nearby` | S | Теги и статусы уже есть, фильтры сделаны только в `/places` |
| Несколько фото у места | M | Сейчас одно фото (`file_id`) |
| Импорт из ссылок на карты (Google, Яндекс, 2GIS): название, координаты и адрес | M | Парсинг ссылки (в том числе коротких, с переходом по редиректу), id организации как сильный ключ склейки мест. Что из этого реально достать без платных API и ключей, выясняем перед реализацией: адрес в самой ссылке бывает не всегда |

## 3. Шаринг и соцчасть
| Идея | Размер | Комментарий |
|---|---|---|
| Live Location: «рядом с вами сохранённое место» | L | Пользователь делится живой геопозицией с ботом; есть нюансы приватности |

## 4. Эксплуатация и безопасность
| Идея | Размер | Комментарий |
|---|---|---|
| Лимиты частоты команд и комментариев (антиспам) | M | Сейчас только лимит 500 мест на пользователя |
| Админ-панель: статистика, скрытые комментарии, блокировки | L | Сейчас модерация только через жалобы (3 жалобы → скрытие) и удаление автором |
| Экспорт метрик (Prometheus), дашборд по `poi.place.resolve.*` | S | Метрики есть, но actuator экспортирует не всё |
| Автоматические бэкапы БД и проверка восстановления | M | Первичная инструкция — `docs/DEPLOY.md` |
| Webhook вместо long polling | M | Нужен публичный HTTPS; позволяет масштабировать на несколько экземпляров |
| Другие языки интерфейса (кроме ru/en) | M | Сейчас `messages_*.properties` и `*_en.ftl` |
| Вычитка текстов и шаблонов целиком (тон, опечатки) | S | Первая вычитка сделана в этапе 4 |

## План по релизам
Выпущены: **0.1** (MVP), **0.2** «Дожать MVP» (карточка после правки, команды и клавиатура геопозиции, геопозиция «просто так», `/deleteme`), **0.3** «Список стал удобным» (поиск, сортировка, фильтры, рейтинг в списках, без дублей в группе), **0.4** «Категории и личное» (теги, статус «хочу сходить / был» и заметка, фильтры по ним в `/places`, `/settings`).

- **0.5 «Рост»:** inline-шаринг; импорт из ссылок карт (Google, Яндекс, 2GIS); срок и отзыв ссылки-приглашения; `/nearby` по местам групп.

### Отложено
Возвращаемся при росте аудитории или реальной необходимости: бэкапы БД (`pg_dump` во внешнее хранилище, не на тот же сервер), лимиты частоты команд, Prometheus и дашборды, админ-панель, webhook, Live Location, несколько фото, новые языки, общая вычитка текстов, подсказка про права админа бота, перенос поиска и сортировки списков в SQL (`ILIKE`/`pg_trgm`) при снятии лимита 500 мест.
